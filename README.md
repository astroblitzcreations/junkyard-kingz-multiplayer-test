# Junkyard Kingz — Multiplayer Test

Downloadable Windows multiplayer test builds for Junkyard Kingz.

## Current build

**Build date:** October 21, 2026  
**Platform:** Windows 64-bit  
**Godot:** 4.7.2 stable

This build contains the latest multiplayer work, automatic CPU fighter/machine
drafting, upgraded water and arena presentation, repair pickups, refreshed crew
selection, Discord-friendly lobby invite links, and all current maps and modes.

## Play

1. Download the **235 MB Windows ZIP** from the release page:
   **[Download JunkyardKingz-Windows.zip](https://github.com/astroblitzcreations/junkyard-kingz-multiplayer-test/releases/download/multiplayer-test-2026-10-21/JunkyardKingz-Windows.zip)**
2. Right-click the ZIP and choose **Extract All**.
3. Open the extracted folder and double-click `JunkyardKingz.exe`.
4. If Windows SmartScreen appears, choose **More info**, then **Run anyway**.

The game data is embedded in the executable, so no separate `.pck` file is
needed.

## One-click Discord lobby invites

Open **Online Garage** once and press **Enable One-Click Invite Links**. After
hosting a lobby, press **Copy Discord Invite Link** and paste the HTTPS link in
Discord. Friends with the game installed can click it to launch the game and
join the lobby automatically; the page also links to this download when the
game is not installed.
