# Junkyard Kingz — Multiplayer Test

Downloadable Windows multiplayer test builds for Junkyard Kingz.

## Current build

**Build date:** October 18, 2026  
**Platform:** Windows 64-bit  
**Godot:** 4.7.2 stable

This build contains the latest multiplayer work, upgraded shaders and vehicle
effects, refreshed crew and Scrap List menus, loading-screen improvements,
showroom presentation, vehicle-selection drop reveal, and current gameplay maps
and modes.

## Play

1. Download the **201 MB Windows ZIP** from the release page:
   **[Download JunkyardKingz-Windows.zip](https://github.com/astroblitzcreations/junkyard-kingz-multiplayer-test/releases/download/multiplayer-test-2026-10-18/JunkyardKingz-Windows.zip)**
2. Right-click the ZIP and choose **Extract All**.
3. Open the extracted folder and double-click `JunkyardKingz.exe`.
4. If Windows SmartScreen appears, choose **More info**, then **Run anyway**.

The game data is embedded in the executable, so no separate `.pck` file is
needed.

> **Do not use Code → Download ZIP.** GitHub repository ZIP files do not include
> the real Git LFS executable and may contain only a tiny pointer file. Use the
> release download link above.
